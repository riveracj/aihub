# Flutter AI Hub Lite Mode — MVP Testing Plan

## Objective

Build a lightweight MVP version of the AI Hub platform focused only on:

* fast development
* performance testing
* UX validation
* scalable architecture preparation
* early user feedback

This version should prioritize:

* simplicity
* speed
* low backend cost
* clean architecture

---

# MVP Scope (Lite Mode)

## Only 3 Main Pages

### 1. Home / AI Hub List

Primary discovery screen.

### Features

* List/Grid of AI hubs
* AI image/avatar
* AI title
* Short description
* User count
* Rating
* “Chat Now” button

### Layout

Simple card-based interface.

---

### 2. AI Details Page

### Features

* AI full description
* Categories/tags
* Example prompts
* Statistics
* Start Chat button

---

### 3. Chat Page

### Features

* Basic messaging UI
* User message
* AI response
* Typing indicator
* Scrollable conversation

---

* lazy loading

* loading all hubs at once
